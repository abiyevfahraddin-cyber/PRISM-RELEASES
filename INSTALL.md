# Install PRISM (Windows)

1. Open the **Releases** section of this repository.
2. Download the official `PRISM-Setup-<version>.exe` asset for the version you were invited to test.
3. Run the installer. Windows may warn that the publisher is unknown — expected without a paid Authenticode certificate.
4. Launch PRISM from the Start menu / desktop shortcut.
5. Optional: in Product menu → **Проверить обновления…** after a signed beta channel is published.

Do not use developer terminals, local `win-unpacked` trees, or test harnesses as the ordinary user path.
